Playnck

Desktop music player · Electron

Playnck is a desktop music player built with Electron, designed around a clean interface and a focused listening experience. It supports local music libraries, playlists, metadata and album artwork, with features such as automatic tagging, audio conversion, playback controls and a responsive interface.

FANET / NS-3 Simulation

Networking research · NS-3

A networking research project focused on Flying Ad-hoc Networks (FANET), using NS-3 to simulate UAV communication, mobility and routing scenarios. The project explores how mobile nodes communicate and coordinate in dynamic network environments.
