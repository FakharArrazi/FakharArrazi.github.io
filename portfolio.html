Project 01 · Software

Playnck

A desktop music player built with Electron, focused on interface detail — from playback controls to the small interactions around a listening session. It handles local library management, automatic metadata detection, album artwork, playlists and fast search, wrapped in a custom, themeable interface.

Project 02 · Research

FANET / NS-3

A networking research and simulation project centered on Flying Ad-hoc Networks (FANET) — mobile aerial nodes that form and maintain a network without fixed infrastructure. Built using the NS-3 network simulator to study routing behavior, mobility and performance as nodes move.
